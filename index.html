    Et design i Figma ser færdigt ud. Først med kode virker det rigtigt: knapper, data, login.

    DesignHvordan ser det ud?

    Et produkt, man kan bruge
    Tid: 08.59–09.01 (2 min.). Pointe: Design og UX beskriver, hvordan noget skal se ud og opføre sig. Koden er strømmen, der får det til at virke. Eksempel: en login-side.     • AI kan skrive kode på få sekunder
    • Men du skal stadig vide, hvad du vil bygge og hvorfor
    • Vi lærer at læse, teste og rette koden
    • Det vigtigste: at kunne forklare den
    Tid: 09.01–09.04 (3 min.). Byg videre på i går (»Brug AI som makker, du har ansvaret«). Gentag det ikke, men gør det konkret for kode. Vi bruger AI til at forklare fejl, foreslå løsninger og lære hurtigere. I dag må I gerne bruge AI til infosiden, men I skal kunne forklare, hvad koden gør.

    Trin 1 · HTML

    HTML er indholdet

    
<!DOCTYPE html>
<html lang="da">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Et glimt af MDU</title>
</head>
<body>
  <h1>Et glimt af MDU</h1>
  <p>Vi designer og koder digitale oplevelser.</p>
  <button>Vis et fun fact</button>
  <p id="fakta"></p>
</body>
</html>

    Fil: index.html

    Tid: 09.08–09.13 (5 min.). Gå gennem fremhævningerne med højre pil: 1) Linje 1–2 og 14: »Det her er en HTML-side, og den er på dansk.« Alt ligger inde i html-tagget. 2) head: info til browseren, som ikke står på selve siden, fx titlen i fanen. 3) body: alt det, man kan se. 4) h1 og p: en overskrift og et afsnit. Tags kommer i par: start og slut. 5) button og en tom p med id="fakta". Her skal vores fun fact stå senere. Pointe ved resultatet: Det virker, men det er grimt. Times New Roman på hvid baggrund, og knappen gør ingenting. Overgang: »Lad os give det noget tøj på.«

    Trin 2 · CSS

    CSS er udseendet

    
body {
  background: #0c1c20;
  color: #f3f4f7;
  font-family: system-ui, sans-serif;
  text-align: center;
  padding: 2rem;
}

h1 { color: #80b4bf; }

button {
  background: #80b4bf;
  border: none;
  border-radius: 999px;
  padding: 0.8rem 1.6rem;
  font-size: 1rem;
}

    Fil: style.css · kobles på i <head> med <link rel="stylesheet" href="style.css">

    Tid: 09.13–09.18 (5 min.). Først: CSS ligger i sin egen fil, style.css, og kobles på med én linje i head. 1) body: baggrund, tekstfarve, skrift, centrering og luft. Farverne er skrevet som farvekoder, fx #0c1c20. 2) h1 får en lyseblå farve. 3) button: samme farve, ingen kant, helt runde hjørner og lidt luft. Nu ligner det en rigtig knap. Spørg: Hvilken farve skal knappen have? Skift farvekoden, og vis forskellen. Overgang: »Den ser god ud, men den gør stadig ingenting. Nu sætter vi strøm til.«

    Trin 3 · JavaScript

    JavaScript er opførslen

    
// 1. En liste med fun facts
const fakta = [
  "MDU tager 2 år – med praktik i en rigtig virksomhed.",
  "Du lærer både design, UX, content og kode.",
  "Du arbejder i projekter sammen med andre."
];

// 2. Find knappen og tekstfeltet på siden
const knap = document.querySelector("button");
const tekst = document.querySelector("#fakta");

// 3. Når der klikkes: vis et tilfældigt fact
knap.addEventListener("click", function () {
  const nr = Math.floor(Math.random() * fakta.length);
  tekst.textContent = fakta[nr];
});

    Fil: script.js · kobles på lige før </body> med <script src="script.js"></script>

    Tid: 09.18–09.23 (5 min.). JavaScript ligger i script.js og kobles på nederst i body. 1) En liste (et array) med tekster. Hver tekst i anførselstegn, og komma imellem. 2) Vi finder knappen og den tomme p på siden. Det er sådan, JS »får fat i« HTML. 3) addEventListener: »Når nogen klikker, så gør det her.« 4) Vælg et tilfældigt nummer, og skriv teksten ind på siden. Pointe: Det er en rigtig, interaktiv side. Og det er præcis den kode, der ligger i jeres starter. Overgang: »Nu prøver I selv, i CodeSandbox.«
